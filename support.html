Technical Support

StartKnowledge projects are designed to provide practical digital tools, but software can occasionally experience errors, compatibility issues, API failures, broken links, browser problems or temporary outages. The support channel is available for reporting these issues.

How to Report a Problem

A useful support request should explain what happened and what you expected to happen. Include the project name, affected page or tool, approximate time of the problem, browser/device information and the steps needed to reproduce the issue.

If an error message appears, copy the non-sensitive error text into the email. Screenshots can also be useful when they do not expose passwords, private information, tokens or confidential data.

Security: Never send passwords, API keys, authentication tokens, private keys or payment-card information in a support email.

Calculator Issues

If a calculator produces an unexpected result, first verify the input values, units and assumptions. Some calculations depend on rules that may change over time.

For pension, financial, government or employment-related calculations, verify important results against appropriate official information.

Website Issues

Website problems can include broken navigation, missing images, layout problems, slow pages, JavaScript errors or browser compatibility issues. Support requests should identify the exact page where the issue occurs.

API Issues

Projects that use APIs can experience quota limits, authentication failures, service outages, response-format changes or rate limiting. External API behaviour may change independently of StartKnowledge.

AI Feature Issues

AI-powered applications may occasionally return incomplete, inaccurate or unexpected output. Such results can be caused by model limitations, prompt interpretation, service availability or third-party API changes.

Before Contacting Support

  • Refresh the page.
  • Check your internet connection.
  • Try a current browser.
  • Check whether the issue is temporary.
  • Verify calculator inputs.
  • Do not share confidential credentials.
